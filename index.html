Tetapan AI (Google Gemini)

Fungsi Tanya AI menggunakan model Gemini 2.5 Flash secara percuma (RM0) untuk mencadangkan pengelasan kod 1PP apabila istilah carian tiada dalam pangkalan data. Kunci API anda hanya disimpan dalam pelayar ini (localStorage).

Cara mendapatkan Kunci API Percuma:
  1. Buka Google AI Studio dan log masuk akaun Google.
  2. Klik Create API key dan salin kod bermula dengan AIza....
  3. Tampal kod tersebut di ruangan di bawah dan klik Simpan.

⚠️ Nota: Sila gunakan akaun Gmail peribadi (@gmail.com) sahaja. E-mel rasmi kerajaan/agensi (.gov.my) tidak dapat digunakan kerana akses Google AI Studio disekat oleh dasar keselamatan pentadbir organisasi.

Kod berjaya disalin!
